# Architecture Decision Records

Sync-engine and plugin-architecture decisions for WCPOS live here, starting at ADR 0033.

Numbers below 0033 appear in older code comments ("ADR 0009", "ADR 0029", …); they refer to
the retired replication-lab prototype and are historical — the reasoning that mattered lives
inline in the docblocks that cite them, and the promoted decisions live in the wiki under
`architecture/decisions/`. Starting at 0033 keeps a future ADR here from ever colliding
with one of those historical citations.
