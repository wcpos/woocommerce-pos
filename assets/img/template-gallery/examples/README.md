# Example pictures for display templates

Placeholder photographs used by the Carousel customer-display template. Merchants replace them
with their own. All three are CC0 (public domain) from Wikimedia Commons, cropped to 16:9 at
1280×720 and encoded as WebP:

- `coffee-beans.webp` — https://commons.wikimedia.org/wiki/File:Coffee_beans_and_white_mug.jpg
- `croissant.webp` — https://commons.wikimedia.org/wiki/File:Morning-breakfast-croissant_(24244330501).jpg
- `latte.webp` — https://commons.wikimedia.org/wiki/File:Latte_art_in_pasadena_(Unsplash).jpg

Templates reach this folder through `{{assets.url}}examples/<name>.webp`; the display host page
sets `assets.url` to the plugin's `assets/img/template-gallery/` folder.
